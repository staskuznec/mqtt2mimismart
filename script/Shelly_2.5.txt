// ИМЕНА СОЗДАВАЕМЫХ ДАТЧИКОВ статичные: "Shelly K0 Мощность" и так далее.
// Поле для названия убрано — подстановка переменной внутрь имени в блоке
// addItems не срабатывала, и введённый текст просто пропадал. Если на одну
// область приходится несколько реле, датчики удобнее переименовать после
// импорта — адреса от переименования не меняются.
//
// КАК СОЗДАТЬ ЛАМПЫ. Скриптом их завести нельзя, поэтому лампы для обоих
// каналов создаются заранее вручную, а в полях выше просто выбираются из
// списка. Датчики мощности, энергии, напряжения и температуры скрипт создаёт
// сам — с ними такой проблемы нет.
//
// Лампы объявляются атрибутом hw в датчике 98:
//
//   hw="virtual:56-LLL"
//
// Здесь 56 — первый свободный sub-id, увеличенный на 8, а каждая буква L
// добавляет одну лампу. В этом примере создадутся 56, 57 и 58.
//
// ВАЖНО: адрес, кратный восьми, работать корректно не будет — в примере это
// как раз 56. Поэтому объявлять нужно с запасом и использовать следующие за
// ним, то есть 57 и 58. Для одного реле Shelly 2.5 нужны две рабочие лампы,
// так что трёх объявленных хватает.
//
// ---------------------------------------------------------------------------
//
// Один скрипт обслуживает реле целиком: обе лампы и все показания.
//
// Пользователь нажимает лампу, а не скрипт. Каждая лампа соответствует своему
// каналу реле: LAMP0 это выход O1, LAMP1 — выход O2.
//
// Обработчик различает два случая.
//
// 0xFF — нажатие в интерфейсе, то есть запрос на переключение. Скрипт берёт
// текущее состояние прямо из элемента, инвертирует его, записывает обратно —
// иначе интерфейс не обновится, элемент своё состояние сам не хранит — и тут же
// отправляет команду реле. Полагаться на то, что запись в лампу породит новое
// событие, нельзя: если платформа его не генерирует, нажатие обновит галку, а
// реле останется нетронутым.
//
// Всё остальное — состояние, выставленное логикой умного дома или привязанным
// выключателем. Здесь важен только младший бит: значения 1 и 9 означают
// включено, 0 и 8 — выключено, старшие биты это флаги, к состоянию отношения не
// имеющие. Поэтому проверка идёт маской (opt(0) & 1), а не перечислением.
//
// Порядок проверок принципиален: 0xFF разбирается ПЕРВЫМ, потому что
// 0xFF & 1 = 1, и по маске нажатие прочиталось бы как "включить".
//
// Теневых переменных состояния в скрипте нет намеренно. Текущее значение
// читается из самого элемента через [LAMP0.0]. Иначе переменная разъезжалась бы
// с интерфейсом: опрос пишет в лампу фактическое состояние реле, скрипт об этом
// не узнаёт, и следующее нажатие переключало бы от устаревшего значения.
//
// Кроме нажатия состояние лампы скрипт не выставляет, и бинарник после команды
// тоже ничего не пишет. Источник состояния — периодический опрос: он читает реле
// и раскладывает фактические значения по элементам. Поэтому изменение с любой
// стороны — из интерфейса реле, кнопкой на самом устройстве, по расписанию —
// доезжает до умного дома одинаково.
//
// Физические выключатели тут ни при чём: они заведены на входы умного дома и
// привязываются к этим лампам его собственной логикой, мимо скрипта.
//
// Скрипт только ОТПРАВЛЯЕТ команды: кладёт текстовый статус элементу DEST, тот
// запускает бинарник, и строка приезжает туда HEX-ом в аргументе.
//
// Формат команды:
//   host|action|channel|цель=id:subid|...
//
//   host    — ip реле, либо user:pass@ip, если включён пароль
//   action  — on | off | toggle | status
//   channel — 0 или 1; для опроса можно не указывать, если у целей есть номер
//   цели    — state, power, energy, overpower (можно с номером канала:
//             state0, power1) и общие для устройства voltage, temp, overtemp
//
// Один запрос status обновляет сразу обе лампы и общие показания: реле
// опрашивается один раз за период, а не по разу на канал.
//
// Почему мощность, энергия и напряжение объявлены как text: протокол передаёт
// числа как fixed-point 8.8, туда влезает только диапазон примерно ±128.
// Ватты, киловатт-часы и 230 В в него не помещаются, поэтому бинарник шлёт их
// строкой с единицами: "41.2 Вт", "3.52 кВ", "231.4 В". Состояние лампы
// уходит одним сырым байтом — у однобайтовых элементов значение датчика
// приехало бы нулём.
//
// Напряжение у Shelly 2.5 одно на устройство: оба выхода питаются от одной
// фазы L, отдельного напряжения на канал прошивка не отдаёт.

// Периодический опрос: одна команда обновляет обе лампы и общие показания.
// Конструкция V-ID/s:[время] сама генерирует событие раз в заданное число
// секунд, перезаводить таймер вручную не нужно.
V-ID/s:POLL_PERIOD {
    if (COLLECT_STATUS == 1) {
        if (DEBUG == 1) {
            srvError("Shelly -> DEST: HOST|status||state0=LAMP0|power0=POWER0|energy0=ENERGY0|state1=LAMP1|power1=POWER1|energy1=ENERGY1|voltage=VOLTAGE|temp=TEMP");
        }
        setStatus(DEST, "HOST|status||state0=LAMP0|power0=POWER0|energy0=ENERGY0|state1=LAMP1|power1=POWER1|energy1=ENERGY1|voltage=VOLTAGE|temp=TEMP");
    }
}

// Лампа канала 0 — выход O1.
V-ID/LAMP0 {
    if (opt(0) == 0xFF) {           // нажатие на элемент в интерфейсе
        if (DEBUG == 1) {
            srvError("Shelly LAMP0: нажатие, было %d", [LAMP0.0] & 1);
        }
        if (([LAMP0.0] & 1) == 1) {
            setStatus(LAMP0, 0);    // для корректного отображения в интерфейсе
            setStatus(DEST, "HOST|off|0|state=LAMP0");
        } else {
            setStatus(LAMP0, 1);
            setStatus(DEST, "HOST|on|0|state=LAMP0");
        }
    } else {                        // состояние выставлено логикой умного дома
        if (DEBUG == 1) {
            srvError("Shelly LAMP0: opt=%d bit0=%d", opt(0), opt(0) & 1);
        }
        if ((opt(0) & 1) == 1) {
            setStatus(DEST, "HOST|on|0|state=LAMP0");
        } else {
            setStatus(DEST, "HOST|off|0|state=LAMP0");
        }
    }
}

// Лампа канала 1 — выход O2.
V-ID/LAMP1 {
    if (opt(0) == 0xFF) {
        if (DEBUG == 1) {
            srvError("Shelly LAMP1: нажатие, было %d", [LAMP1.0] & 1);
        }
        if (([LAMP1.0] & 1) == 1) {
            setStatus(LAMP1, 0);
            setStatus(DEST, "HOST|off|1|state=LAMP1");
        } else {
            setStatus(LAMP1, 1);
            setStatus(DEST, "HOST|on|1|state=LAMP1");
        }
    } else {
        if (DEBUG == 1) {
            srvError("Shelly LAMP1: opt=%d bit0=%d", opt(0), opt(0) & 1);
        }
        if ((opt(0) & 1) == 1) {
            setStatus(DEST, "HOST|on|1|state=LAMP1");
        } else {
            setStatus(DEST, "HOST|off|1|state=LAMP1");
        }
    }
}
