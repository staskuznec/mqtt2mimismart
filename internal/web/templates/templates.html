Профили устройств

Профиль описывает, какие связки нужны модели и какие элементы под них назначить. Развернуть десяток связок — одно действие. Лежат они файлами в {{.Dir}}: туда можно положить свой, а можно завести прямо здесь.

Поставляемые профили обновляются вместе со шлюзом и остаются эталонными. Правка такого профиля сохраняется отдельным файлом <ключ>.local, и устройства, заведённые по нему, переезжают на копию: так правка не теряется, а исправления из поставки перестают ходить мимо объекта.

Как устроен шаблон

Как устроен профиль — развернуть описание формата

Шаблон состоит из двух списков. Роли — то, что предстоит назначить при развёртывании: какой элемент умного дома отвечает за канал, какой за мощность. Связки — что из этого получится: топик, форма значения, единица, множитель. Пользователь выбирает элементы, всё остальное уже расставлено вами.

Подстановка {{"{{prefix}}"}} в топике обязательна — на её место встаёт мастер-топик устройства, например shellies/shellyswitch25-4022D8956527. Роль, для которой элемент не выбран, пропускается вместе со своими связками: так одним шаблоном покрывается и полностью заведённое устройство, и то, от которого нужен один канал.

Поле ролиЧто задаёт
keyидентификатор, на него ссылаются связки
titleкак роль называется в форме развёртывания
formbyte, sensor или text — подсказка, какой элемент подходит
hintпояснение под названием
requiredtrue — без неё шаблон не применить
Поле связкиЧто задаёт
nameназвание связки; внутри шаблона должно быть уникальным
directionin — с шины в умный дом, out — обратно
roleиз какой роли берётся элемент
topicтопик с подстановкой {{"{{prefix}}"}}
pairметка пары: две связки с одной меткой заводятся и удаляются вместе
encodeформа записи для in: byte, sensor, text
decodeчтение элемента для out: lamp, byte, sensor, text
kindдля out: command — команда устройству, state — показание наружу
valuesтаблица перевода: {"on": "1", "off": "0"}
unitприписка к тексту, например " Вт"
precisionзнаков после запятой; не указано — без округления
scaleмножитель; ватт-минуты в кВт·ч это 0.0000166667
qos0, 1 или 2; для команд разумно 1
retainтолько для kind: state; на команде запрещён
only_changedотсев повторов; по умолчанию включён

Форматирование величин

Чтобы показания выглядели одинаково во всех профилях: мощность и напряжение — без знаков после запятой ("unit": " Вт", "precision": 0), энергия — один знак, единица " кВт", множитель 0.0000166667: счётчик у Shelly считает в ватт-минутах.

Три вещи, на которых легко обжечься

Форма значения. У ламп, штор, скриптов и клапанов состояние занимает ровно один байт. Если задать им sensor, единица уедет как 00 01, младший байт окажется нулевым, и элемент останется выключенным — при том что выключение будет «работать». Ищется такое долго.

retain на команде. Брокер отдаст сохранённую команду устройству при следующем его подключении, и реле щёлкнет само. Проверка это отвергнет, но знать причину полезно.

Единицы счётчиков. У Shelly энергия считается в ватт-минутах, и ошибка в множителе тихая — ровно в шестьдесят раз.

Пример

{
  "name": "Розетка с измерением",
  "model": "SHPLG-S",
  "note": "Один канал, мощность и энергия.",
  "roles": [
    {"key": "sw",     "title": "Розетка", "form": "byte", "required": true},
    {"key": "power",  "title": "Мощность, Вт", "form": "text"}
  ],
  "links": [
    {
      "name": "Состояние", "direction": "in", "role": "sw", "pair": "sw",
      "topic": "{{"{{prefix}}"}}/relay/0",
      "encode": "byte",
      "values": {"on": "1", "off": "0", "overpower": "1"}
    },
    {
      "name": "Команда", "direction": "out", "role": "sw", "pair": "sw",
      "topic": "{{"{{prefix}}"}}/relay/0/command",
      "kind": "command", "decode": "lamp", "qos": 1,
      "values": {"on": "on", "off": "off", "toggle": "toggle"}
    },
    {
      "name": "Мощность", "direction": "in", "role": "power",
      "topic": "{{"{{prefix}}"}}/relay/0/power",
      "encode": "text", "unit": " Вт", "precision": 1
    }
  ]
}

Проще всего начать с готового: нажмите «открыть» у встроенного шаблона, скопируйте, поправьте под свою модель и загрузите под новым ключом.
